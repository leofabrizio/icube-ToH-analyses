# icube-ToH-analyses
This repository contains dataset and analysis scripts of the paper ***Mental Rotation Ability Skill Shapes Haptic Exploration Strategies***

The file **data.csv** contains the dataset and the file **data_codebook.pdf** describes the variables included in the dataset. The script **analyses.py** contains the main code I used to analyze the dataset. It is organized in separated chunks delimitated by this graphical convention: #%%%%%%%%%%%%%

I included some comments explaining the code but, as the code was not originally prepared to be shared but only to get results, I cannot exclude there are parts not sufficiently clear. In this case, please feel free to contact me at fabrizio.leo@gmail.com and I will be more than happy to help out.
